# Verb Practice

Карточки английских неправильных глаголов по типам изменений.

**Сайт:** https://lasveta1sl-bot.github.io/irregular-verbs-trainer/

## Что внутри

- Все 103 глагола с предоставленной фотографии.
- 106 карточек: дополнительно выделены значения hang / shine и конструкция be able to.
- 5 основных разделов, 25 моделей изменений, включая beat → beat → beaten (A → A → B).
- Лицевая сторона: Infinitive и перевод. Оборот: Past Simple и Past Participle, варианты и примечания.
- 303 аудиофрагмента авторской записи для 101 карточки. На лицевой стороне звучит первая форма; на обороте последовательно вторая и третья.
- Sew использует только исправленную запись «Новая запись 7».
- Медленное воспроизведение, перемешивание, светлая / тёмная тема, мобильная вёрстка.
- Выбранная группа, модель, скорость и тема сохраняются в этом браузере.

Без озвучки: beat, can, be able to, hang в значении «казнить через повешение» и shine в значении «начищать до блеска». Дополнительные варианты форм отображаются текстом. У can нет третьей формы.

## Открыть локально

Откройте `index.html` в современном браузере. Сервер, npm и сборка не требуются. Для проверки через локальный сервер при наличии Python:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`.

## Файлы

- `index.html` — страница и шаблон карточки.
- `styles.css` — адаптивное оформление.
- `app.js` — карточки, управление аудио и настройки.
- `data.js` — глаголы, модели изменений, примечания и ссылки на аудио.
- `audio.js` — аудиофрагменты MP3, упакованные в data URLs для работы без сервера.
- `audio-map.json` — границы фрагментов в исходных записях, в секундах; source `main` — запись 6, `sew` — запись 7.

Исходные длинные записи в репозиторий не включены. Аудио размечено локально по паузам и проверено по распознанному порядку слов. Перед использованием на занятиях рекомендуется прослушать карточки и проверить произношение.

## Предложения по фреймам

`frames.html` — 103 карточки, сгруппированные по 10 конструкциям. Английское предложение на лицевой стороне, русский перевод на обороте. Всё в Present Simple; первая форма глагола без -s. Для be грамматически необходима личная форма: We are happy. Предложения без озвучки: авторские записи содержат отдельные формы глаголов.
